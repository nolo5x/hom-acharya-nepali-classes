# Hom Acharya | Nepali Language Teaching Website

A responsive, multi-page educational website showcasing **Hom Acharya, Ed.D.**, his Nepali language teaching experience, course offerings, teaching philosophy, and learning resources.

The website helps prospective learners explore Nepali language instruction—from beginner to advanced levels—and inquire about personalized lessons.

> **Live website:** Add your GitHub Pages URL here after deployment: `https://YOUR-USERNAME.github.io/hom-acharya-nepali-classes/`

## About the Instructor

**Hom Acharya, Ed.D.** is a Nepali language educator with more than 27 years of teaching experience across Nepal, Japan, and the United States. He is a Nepali language faculty member at Cornell University.

His teaching emphasizes student-centered learning, practical communication, and understanding language in its cultural context. Lessons can be tailored to students' backgrounds, proficiency levels, and learning goals.

[View Cornell faculty profile](https://asianstudies.cornell.edu/hom-acharya)

## Website Features

- **Responsive navigation:** Desktop links and a mobile hamburger menu.
- **Instructor biography:** Teaching background, education, and professional experience.
- **Nepali courses:** Ten course levels from Beginner 1 through Advanced 2.
- **Teaching philosophy:** Communicative, student-centered, culturally integrated instruction.
- **Language and culture:** Topics such as traditions, festivals, food, music, literature, and heritage.
- **Learning resources:** Teaching materials, digital learning tools, assessments, and lesson planning.
- **Student experiences:** A section prepared for authentic, permission-based testimonials.
- **Contact and enrollment:** An inquiry form that prepares an email in the visitor's email application.
- **Course-aware inquiries:** Links from course pages can preselect a course on the contact form.

## Run Locally

1. Download or clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/hom-acharya-nepali-classes.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use a local development server such as the VS Code Live Server extension.
4. Navigate through the pages to explore the website.

## Publish with GitHub Pages

1. Upload the website files to the root of the repository.
2. Open **Settings → Pages** in GitHub.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` directory, then save.
5. After deployment, visit:

   ```text
   https://YOUR-USERNAME.github.io/hom-acharya-nepali-classes/
   ```

Replace `YOUR-USERNAME` with the repository owner's GitHub username.

## Contact Form Behavior

The contact form uses a `mailto:` link to prepare an inquiry addressed to **homacharya.ranju@gmail.com**. The visitor must have an email application configured and must manually review and send the message.

**The form does not automatically submit emails, store messages, or provide server-side processing.** A form service or backend would be needed for direct website submissions.
